# 和乐创意城小红书热点雷达

这是一个只读 MCP 服务：它把红狐的小红书数据能力收敛成 4 个适合商业体内容策划的工具，再由 ChatGPT 完成选题、爆款拆解和文案建议。

## 安全原则

- 红狐密钥只保存到部署平台的机密变量 `REDFOX_API_KEY`，不放入本仓库、镜像、浏览器或 ChatGPT 提示词。
- 服务不提供任意 URL 请求、写入、下载或账户管理工具；仅暴露小红书检索与分析所需的只读能力。
- 不记录请求头，也不输出环境变量。生产环境请关闭或脱敏访问日志。
- 请立即在红狐后台撤销此前曾发入聊天的旧密钥，并创建新的专用密钥。

## 部署

1. 将本目录部署到任意支持 Docker 的 HTTPS 平台（Render、Railway、Fly.io、阿里云/腾讯云容器服务均可）。
2. 在平台的 **Secrets / Environment Variables** 新建 `REDFOX_API_KEY`，粘贴新建的红狐密钥；不要把它填入任何文件。
3. 平台暴露 `8080` 端口。部署后将 MCP 地址设为 `https://你的域名/mcp`；在 ChatGPT 的 Scan Tools 阶段会完成连通性检查。

## 接到 ChatGPT / Work

ChatGPT 连接的是远程 MCP，不能直接连接你电脑上的这个服务。适用条件与设置请以官方页面为准：

1. 以 ChatGPT Business、Enterprise 或 Edu 的管理员/所有者身份，在网页端启用 Developer mode。
2. 在 Workspace Settings → Apps → Create 中创建自定义 App。
3. MCP endpoint 填 `https://你的域名/mcp`；本模板的 MCP 层无需用户登录授权。
4. 点击 Scan Tools，先在草稿状态用下方的验收提示词测试；确认结果后再发布给指定人员。

个人 Pro 若已获得 Developer mode，可用只读 MCP 测试；完整 MCP 支持的可用性以当前工作区计划与管理员策略为准。

## 常用提问

- `@和乐创意城热点雷达 查最近7天佛山、乐从、顺德、商场、市集、周末遛娃的小红书机会，给5个优先级选题。`
- `@和乐创意城热点雷达 用黑马笔记数据，拆解“佛山商场”和“乐从探店”近30天的内容钩子、封面、标题和评论需求。`
- `@和乐创意城热点雷达 做本周选题会：给出3条可当天拍摄的笔记方案，每条含标题、首图、镜头清单、正文框架、标签与风险提示。`

## 验收标准

- 只返回公开内容数据与分析，不要求、回显或猜测密钥。
- 返回内容须标注查询日期、关键词和数据局限；“佛山/乐从”结果不足时，要明确说明并扩展到顺德/广州佛山同城生活方式作为参照。
- 选题建议不得虚构活动、商户、优惠或数据；有待确认的项必须标为“待运营确认”。

## 本地运行（仅开发验证）

将 `env.example` 复制为本机环境变量后执行：

```bash
pip install -r requirements.txt
python server.py
```

不要把 `.env` 上传到 Git、网盘或聊天窗口。生产环境优先采用云平台的 Secret 管理，而非 `.env` 文件。
